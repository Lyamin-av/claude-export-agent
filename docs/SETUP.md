# Установка и эксплуатация

[← к описанию проекта](../README.md)

## Разовая настройка

1. **Python-окружение.** Откройте папку в PyCharm и создайте venv.
   Затем выполните `pip install -r requirements.txt`.
2. **Модель.** Либо ключ Claude API (https://console.anthropic.com → API Keys),
   либо локальная модель в Ollama — см. раздел [«Локальная модель через Ollama»](#локальная-модель-через-ollama).
3. **Пароль приложения Gmail.** Для него нужна включённая двухэтапная проверка.
   Создайте пароль на https://myaccount.google.com/apppasswords.
   Это 16 символов, основной пароль от Gmail сюда не подходит.
4. **Приватный репозиторий.** На GitHub нажмите New repository, укажите имя
   `claude-export-archive` и выберите Private. Агент склонирует его сам. При первом
   push Git for Windows откроет окно входа в GitHub (Git Credential Manager).
5. **Файл `.env`.** Скопируйте `.env.example` в `.env` и заполните.
   Файл `.env` в Git не попадает.

## Локальная модель через Ollama

Проверено на ноутбуке с RTX 4060 Laptop (8 ГБ видеопамяти) и 32 ГБ памяти.

1. **Установить Ollama:** `winget install Ollama.Ollama` или установщик с ollama.com/download.
   После установки перезапустите терминал, иначе команда `ollama` не найдётся.
2. **Задать переменные Windows** и перезапустить Ollama из трея (Quit → запустить снова):
   ```powershell
   setx OLLAMA_CONTEXT_LENGTH 32768   # окно контекста; по умолчанию 4k — мало для агента
   setx OLLAMA_FLASH_ATTENTION 1      # экономия видеопамяти
   setx OLLAMA_KV_CACHE_TYPE q8_0     # экономия видеопамяти
   ```
3. **Скачать модель:** `ollama pull qwen3.5:9b` (6,6 ГБ).
4. **Проверить:** `ollama run qwen3.5:9b --verbose "Привет"`, затем `ollama ps`.
   В колонке PROCESSOR в идеале `100% GPU`. Если часть модели на CPU — работает, но медленнее;
   можно уменьшить `OLLAMA_CONTEXT_LENGTH` до 16384 или закрыть браузеры на время прогона.
5. **В `.env`:**
   ```
   PROVIDER=openai
   MODEL=qwen3.5:9b
   # OPENAI_BASE_URL=http://localhost:11434/v1   (это значение по умолчанию)
   ```
6. **`python check_setup.py`** — в строке LLM должно быть «вызвала ping(...)»: модель
   отвечает и умеет вызывать инструменты.

Вернуться на Claude: `PROVIDER=anthropic` и `MODEL=claude-haiku-5-5` (нужен `ANTHROPIC_API_KEY`).

Размышления модели печатаются строками 💭; отключить — `SHOW_REASONING=0` в `.env`.

## Каждый запуск
1. На claude.ai откройте Settings → Privacy → Export data. Это делается вручную.
2. Дождитесь письма. **Ссылки живут не больше 24 часов**, поэтому агента
   нужно запустить в течение суток.
3. Убедитесь, что в браузере по умолчанию выполнен вход в claude.ai.
4. Запустите `python agent.py`. Браузер откроет несколько вкладок и скачает файлы.
   Если браузер спросит, разрешить ли сайту скачивать несколько файлов, разрешите.

## Если часть файлов не пришла
Агент покажет, какие файлы отсутствуют. Ссылки одноразовые, поэтому повторно он их
не открывает. Скачайте недостающие zip вручную по ссылкам из манифеста в «Загрузки»
и запустите агента снова: полученные файлы он пропустит.

Если «Загрузки» у вас не в стандартном месте (например, в OneDrive), укажите
путь в `DOWNLOADS_DIR` в `.env`.

## Что лежит в репозитории архива
- `chats/` — переписка в читаемом виде: финальная ветка каждого чата, без служебных
  блоков (рассуждений модели, системных вставок); вызовы инструментов — одной строкой.
- `conversations/`, `projects/`, `memories/`, … — исходные данные экспорта как есть.
- Сообщение коммита пишет модель по фактам из `summarize_changes`: сколько чатов
  новых, какие продолжены, переименованы, удалены.

## Журнал и стоимость
Каждый запуск сохраняется в `work/runs/<дата_время>.json`: все шаги, вызовы
инструментов с результатами и временем, токены, время ожидания модели по шагам.
В конце запуска печатается сводка по токенам и времени. Чтобы видеть ещё и стоимость, укажите в `.env` цены модели
за 1 млн токенов: `PRICE_INPUT_PER_MTOK` и `PRICE_OUTPUT_PER_MTOK`.
